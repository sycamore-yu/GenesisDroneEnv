# Triage labels（分诊状态）

| 标准状态 | 本项目状态 | 含义 |
| --- | --- | --- |
| `needs-triage（需要分诊）` | `needs-triage（需要分诊）` | 等待维护者判断 |
| `needs-info（需要信息）` | `needs-info（需要信息）` | 等待补充信息 |
| `ready-for-agent（可交给智能体）` | `ready-for-agent（可交给智能体）` | 规格完整，可以实现 |
| `ready-for-human（需要人工）` | `ready-for-human（需要人工）` | 必须由人工执行 |
| `wontfix（不处理）` | `wontfix（不处理）` | 不计划处理 |
