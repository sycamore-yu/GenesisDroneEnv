# 使用解析安全距离和平方 Softplus 势函数

当前空旷航点任务不依赖 Genesis 接触事件提供训练梯度。环境先计算连续安全距离：地面距离是 URDF 圆柱碰撞体最低世界坐标点到地面的物理净空；横向距离分别为 `5 - |x_rel|` 和 `5 - |y_rel|`；竖向距离为 `1.2 - |z_rel|`。物理净空用于提供随姿态变化的低空梯度；为与旧 PPO 公平比较，地面硬终止仍使用机体中心高度 `z < 0.1 m`。

每个距离使用归一化平方 Softplus 势函数：

`phi(d) = [softplus((d_warn - d) / tau) / softplus(d_warn / tau)]²`

该函数在距离 `d=0` 时归一化为 1，远离危险时平滑趋近 0，且预警点附近的导数连续。默认 `tau = 0.1 * d_warn`。地面物理净空预警距离为 `0.20 m`；`x/y` 边界预警距离为 `0.50 m`，即相对误差达到 `4.5 m`；`z` 边界预警距离为 `0.12 m`，即相对误差达到 `1.08 m`。

机体中心高度低于 `0.1 m`，任一解析状态边界距离小于等于零，或状态出现非有限值时，产生首次固定终止损失并硬终止。Genesis 刚体接触碰撞在可微训练中保持关闭。未来杂乱环境可以增加无人机采样点和可微 SDF 查询，但不在当前实现中增加 SDF、通用距离类层级或碰撞抽象。
