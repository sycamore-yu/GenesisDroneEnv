# DiffAero Racing 与 Genesis 七门基线语义对照

## 结论

当前 `RaceEnv（竞速环境）` 是 Genesis 功能基线，不是 DiffAero Racing（DiffAero 竞速）复现。两者在赛道、观测、重置、成功条件、损失、奖励、动作、动力学和时间步上均不等价。后续必须新增独立的 DiffAero 兼容环境，不修改七门环境的来源语义。

上游依据固定为 DiffAero 提交 `291ea14`：

- `env/racing.py（竞速环境源码）`
- `cfg/env/racing.yaml（竞速环境配置）`
- `cfg/dynamics/quad.yaml（完整四旋翼配置）`
- `cfg/algo/ppo.yaml（近端策略优化配置）`
- `dynamics/quadrotor.py（完整四旋翼动力学）`
- `dynamics/controller.py（机体角速度控制器）`

## 语义对照矩阵

| 项目 | Genesis 七门功能基线 | DiffAero 上游 Racing（竞速） | 结论 |
| --- | --- | --- | --- |
| 来源 | `genesis_drones/envs/race_env.py（Genesis 竞速环境）` | `env/racing.py（DiffAero 竞速环境）` | 独立任务 |
| 门数量 | 7 门，跑完即结束 | 8 门，索引循环，不因跑完一圈结束 | 不等价 |
| 门位置 | `(0,0,2.0668)`、`(10,5,1.0668)`、`(10,-5,1.0668)`、`(-5,-5,3.5668)`、`(-5,-5,1.0668)`、`(5,0,1.0668)`、`(0,5,1.0668)` | 由半径 `1.5 m`、高度 `1.5 m` 得到：`(1.5,-1.5,1.5)`、`(0,0,1.5)`、`(-1.5,1.5,1.5)`、`(0,3,1.5)`、`(1.5,1.5,1.5)`、`(0,0,1.5)`、`(-1.5,-1.5,1.5)`、`(0,-3,1.5)` | 不等价 |
| 门偏航角 | `0, 0, 5π/4, π, 0, π/2, π` | `π/2, π, π/2, 0, -π/2, -π, -π/2, 0` | 不等价 |
| 门洞与碰撞几何 | 矩形门洞 `1.524 × 1.524 m`，外框 `2.1336 × 2.1336 m`，深度 `0.1323 m`，安全半径 `0.06 m`；可选 Genesis 物理接触 | 源码硬编码 `gate_size=3`；穿门后的门坐标满足 `|y|+|z|<1.5` 才算通过。没有物理门接触 | 不等价；DiffAero 使用菱形判定区 |
| 初始目标门 | 固定第 0 门 | 每次重置在 8 门中均匀随机 | 不等价 |
| 初始位置 | 第 0 门法向后方 `2 m`，三个位置分量各加 `[-0.1,0.1] m` 噪声 | 随机目标门法向后方 `1 m`，无位置噪声 | 不等价 |
| 初始姿态和速度 | 偏航对准第 0 门并加 `±5°`；线速度各分量为 `[-0.1,0.1] m/s` | 四旋翼单位四元数，速度和角速度为 0 | 不等价 |
| 随机目标速度 | 无 | 每次重置从 `[5,10] m/s` 均匀采样 | 缺失 |
| 演员观测 | 40 维：姿态 6 维表示、机体系速度、机体系角速度、上一动作、当前门四角点、下一门四角点 | 默认 13 维：当前门坐标系中的相对位置 3、速度 3、相对滚俯偏 3、下一门相对位置 3、下一门相对偏航 1 | 不等价 |
| 评论家观测 | 演员 40 维加剩余门数，共 41 维 | 34 维：世界速度 3、四元数 4，以及当前和后两门各自的相对位置、速度、滚俯偏，共 27 维 | 不等价 |
| 下一门信息 | 当前门和下一门的绝对四角点转换到机体系 | 下一门相对位置和相对偏航；评论家额外看后两门 | 不等价 |
| 配置中的观测坐标系 | 机体系为主 | 配置写 `world（世界）`，但默认 13 维实现实际使用门局部坐标系 | 以源码实现为准 |
| 时间步 | `0.01 s` | `0.0333 s` | 不等价 |
| 积分器和子步 | Genesis 默认刚体求解器；1 个全局子步。项目没有固定与 DiffAero 相同的积分算法 | 完整四旋翼使用四阶 Runge–Kutta（四阶龙格－库塔积分），1 个子步 | 不等价 |
| 最长回合 | 3000 步，即 `30 s` | `max_time=40 s`，步数为 `int(40/0.0333)=1201` | 不等价 |
| 穿门逻辑 | 使用前后位置线段与门平面的交点；要求正向穿过矩形安全门洞 | 只检查前一步在门后、当前步在门前；使用当前步位置的门局部 `y,z` 做菱形判定 | 不等价 |
| 门碰撞逻辑 | 连续门框有符号距离、越框穿越、可选物理接触均可触发 | 只有穿过门平面且不在菱形门洞内时触发 | 不等价 |
| 越界逻辑 | 机体中心低于 `0.1 m`、门碰撞、物理接触或非有限状态会终止；没有水平和上方边界 | `|x|>5 m`、`|y|>5 m` 或 `z>7 m` 会截断；没有地面下界 | 不等价 |
| `terminated（真实终止）` | 碰撞、完成七门或非有限状态 | 门碰撞 | 不等价 |
| `truncated（时间或边界截断）` | 3000 步时间上限 | 40 秒时间上限、越界或界面重置 | 不等价 |
| 成功定义 | 完成第 7 门且没有碰撞 | 存活到时间上限；与通过多少门无直接关系。通过门数另作统计 | 根本不等价 |
| 赛道循环 | 单圈，完成后结束 | 8 门循环，可连续多圈；记录累计通过门数 | 不等价 |
| 通过门当步的进度目标 | 在更新门索引前计算，仍指向刚穿过的门 | 先更新到下一门，再计算损失和奖励 | 不等价 |
| 完整四旋翼可微损失 | `0.4×进度 + 0.01×加速度² + 0.001×加速度变化率² + 0.4×门向量场 + 3×连续门框安全损失` | `1×速度损失 + 0.001×角速度范数 + 3×目标位置损失 + 0.1×横滚俯仰损失` | 不等价 |
| 完整四旋翼强化学习奖励 | `0.4×速度朝门 + 5×穿门 + 10×完成 - 10×碰撞 - 0.01×动作变化²` | `-0.1×角速度范数 - 10×到门距离增量 - 10×门碰撞`；没有穿门奖励和完成奖励 | 不等价 |
| 动力学 | Genesis 刚体四旋翼，质量 `0.5 kg`，惯量对角线均为 `1.4e-3 kg·m²` | 可选 PMD（离散点质量）、PMC（连续点质量）和完整四旋翼；首个组合使用完整四旋翼 | 不等价 |
| 动作语义 | 4 维归一化总推力与机体角速度；总加速度范围 `[0,3.3g]`，角速度范围 `±(6,6,3) rad/s`；PID（比例－积分－微分）控制后分配到电机 | 4 维归一化动作映射到归一化推力 `[0,5]` 和机体角速度 `[-3.14,3.14] rad/s`；角速度比例增益为 1 | 不等价 |
| 完整四旋翼物理参数 | 固定质量、惯量、臂长 `0.1 m`、推力系数 `3.16e-10`、力矩系数 `7.94e-12` | 质量 `[0.8,1.2] kg`、臂长 `[0.1,0.2] m`、力矩常数 `[0.01,0.0166]`、横向惯量 `[0.008,0.012]`、偏航惯量 `[0.015,0.025]`、阻力 `[0.5,0.7]` | 不等价 |
| 领域随机化 | 只随机初始位置、偏航和速度；不随机物理参数 | 每次重置随机质量、臂长、力矩常数、惯量和阻力，并随机目标门和目标速度 | 大量缺失 |
| 默认训练预算 | 当前七门 PPO（近端策略优化）：256 环境、2000 次迭代、每环境 80 步 | 上游默认：1024 环境、1000 次更新、16 步展开 | 不等价 |
| PPO（近端策略优化）参数 | 学习率 `0.001`、折扣 `0.999`、熵 `0.01`、4 个小批次、5 个训练轮次、网络 `128×128×128` | 学习率 `0.0026`、折扣 `0.99`、熵 `0.01`、8 个小批次、4 个训练轮次、网络 `256×128` | 不等价 |
| 默认评价协议 | 固定 100 个带校验和的初始状态；成功是完成七门 | 上游测试默认 4096 环境、10000 步、关闭领域随机化、目标速度固定 `5 m/s`；统计存活成功率和累计过门数 | 不等价 |

## 首个明确复现组合

首个组合不自行选择，直接采用已有 DiffAero 运行快照中的配置：

- 环境：`racing（竞速）`
- 动力学：`quad（完整四旋翼）`
- 算法：`ppo（近端策略优化）`
- 网络：`mlp（多层感知机）`，隐藏层 `256×128`
- 传感器配置：`relpos（相对位置）`；Racing 源码的默认观测不读取该传感器
- 时间步：`0.0333 s`
- 展开长度：16
- 训练环境数：1024
- 更新数：1000
- 随机种子：0
- 上游命令：`python script/train.py env=racing dynamics=quad algo=ppo network=mlp sensor=relpos seed=0`

现有上游档案只做了 64 环境、1 次更新的运行检查，不能作为训练结果基线。新上游运行必须保留默认 1024 环境和 1000 次更新，除非先明确标记为冒烟测试。

## 最小实现方案

1. 保留 `RaceEnv（七门功能环境）` 不变。
2. 新增独立 `DiffAeroRacingEnv（DiffAero 兼容竞速环境）` 和独立配置；直接编码上游 8 门位置、偏航、循环和重置语义。
3. 第一阶段只实现 13 维演员观测、34 维评论家状态、上游穿门/碰撞/越界/成功语义，以及完整四旋翼损失和奖励。
4. 新增上游兼容机体角速度动作映射和物理参数配置；不要复用当前七门的动作范围和奖励权重。
5. 用纯函数测试锁定门几何、13/34 维观测、随机门重置、穿门碰撞、损失奖励和终止截断。
6. 保存一组上游固定输入的一步输出，做 Genesis 一步行为对照；物理求解器不同的量使用容差和分量对比，不要求整段回报完全相同。
7. 用上游原生配置先跑完整四旋翼加 PPO（近端策略优化），再在 Genesis 运行同一组合；比较训练曲线、损失奖励分量、通过门数、碰撞、存活和轨迹。
8. 该组合闭环后，才扩展 PMD（离散点质量）、PMC（连续点质量）、APG（解析策略梯度）、随机 APG、SHAC（短视域演员—评论家）和 SHA2C（短视域非对称演员—评论家）。
