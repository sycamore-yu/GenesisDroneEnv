# 从竞速到动态避障的长期路线图

**状态：** 活跃路线图。它记录已经决定的长期方向，不等于当前实施范围。

## 目标

最终目标是在真实无人机上获得可靠的竞速和动态避障策略。项目先用状态竞速建立共同的
动力学、控制、任务和评价基线；再把真实 Mid-360（激光雷达型号）感知与 D.VA（解耦视觉
解析策略梯度）引入独立的动态避障任务。

当前详细实施规格是[固定七门竞速第一阶段规格](../../.scratch/fixed-seven-racing-phase1/spec.md)。
它只覆盖下面路线图中的“竞速第一阶段”。

## 全局结构

```text
共同基础
  无人机 + CTBR（总推力与机体角速度指令）+ Genesis（仿真器）动力学
  + 状态估计接口 + 共享任务指标
                 |
                 +-- 状态竞速
                 |     固定七门 -> 多固定赛道 -> 受约束随机赛道 -> 未见赛道
                 |     方法：ppo（近端策略优化）、apg（解析策略梯度）、shac（短视域演员—评论家算法）
                 |
                 +-- 感知动态避障
                       Mid-360（激光雷达）+ 状态估计 + 目标方向
                       方法：Mid360-PPO（激光雷达近端策略优化）、dva（解耦视觉解析策略梯度）
                       静态杂乱 -> 动态障碍历史 -> 距离加点流 -> 真实部署
```

两条路线共享飞行器、控制链和物理仿真，但不共享演员输入。竞速演员读取已知赛道地图下的
门几何；动态避障演员读取传感器特征和目标方向。未来不得把这两个输入来源混成一个没有
边界的任务。

## 已冻结的共同原则

- 控制周期保持 0.01 秒，即 100 Hz（每秒 100 次）。
- 三种竞速算法都使用同一个 CTBR（总推力与机体角速度指令）正向控制链。
- 任务事件、赛道、初始状态、时间上限和最终评价必须共享；训练损失或奖励可以按算法不同。
- 演员只能读取未来真实部署时可获得的信息。训练评论家和训练损失可以读取仿真真值。
- 硬接触事件不承担可微训练梯度。可微训练使用连续距离或连续几何损失；最终评价使用真实
  Genesis（仿真器）接触。
- 算法命名固定为 `ppo（近端策略优化）`、`apg（解析策略梯度）`、`shac（短视域演员—评论家算法）`
  和未来的 `dva（解耦视觉解析策略梯度）`。

## 路线一：状态竞速

### 阶段 R1：固定七门可靠完成

这是当前唯一允许实施的阶段。

- 赛道：原始 1 到 7 门顺序，保留第四门到第五门的 Split-S（分体 S 弯）。
- 门信息：已知赛道地图加状态估计，不研究门识别。
- 演员：40 维局部状态和当前、下一门四角点。
- 方法：PPO（近端策略优化）、完整 APG（解析策略梯度）、SHAC（短视域演员—评论家算法）。
- APG（解析策略梯度）：完整 BPTT（时间反向传播），不切断状态到下一次策略的梯度。
- SHAC（短视域演员—评论家算法）：短物理窗口加冻结目标评论家的终端成本；真实终止不自举，
  时间截断继续自举。
- 验收：每种算法 3 个训练种子，每个模型 100 个固定评价初始状态；完整七门成功率至少 90%，
  碰撞率不高于 5%。

### 阶段 R2：多种固定赛道

固定七门通过后，使用相同赛道描述录入多种门数、门高、转弯方向、门距和整体形状的赛道。
这些赛道不从 Isaac Drone Racer（无人机竞速框架）导入；只参考其公开配置形式。

进入条件：R1 的三种算法都通过可靠性验收。

### 阶段 R3：受约束随机赛道和未见赛道

随机赛道由圆形、顺时针或逆时针、折线、直线加转弯和椭圆等赛道基本形状组合。必须限制门间
距离、转弯角度、高度变化和可飞性，不能直接随机坐标。MasterRacing（多赛道无人机竞速方法）
提供基本形状思路，LSY Drone Racing（无人机竞速框架）提供空间净空和回退采样思路。

进入条件：R2 中不再只依赖单一赛道完成任务。

### 阶段 R4：速度优化

在可靠完成和泛化已达标后，才把完成时间、每门时间、平均速度和路径效率转为主要目标。
此时可比较更长 APG（解析策略梯度）窗口和时间梯度衰减，但不在 R1 提前实现。

## 路线二：Mid-360（激光雷达）动态避障

感知动态避障是独立任务。它不要求从激光雷达识别竞速门，也不改变 R1 到 R4 的竞速结论。

### 阶段 A0：状态真值安全任务

先用状态真值建立静态杂乱和动态障碍物任务。此阶段的目的只是验证目标、终止、连续安全损失
和障碍物运动；它不是可部署策略结果。

- 状态 APG（解析策略梯度）和状态 SHAC（短视域演员—评论家算法）可用于检查可微安全损失。
- PPO（近端策略优化）可作为事件奖励基线。
- 动态安全损失可读取训练期障碍位置、半径和速度，并结合接近速度。

### 阶段 A1：Mid-360（激光雷达）物理采样和静态杂乱基线

传感器物理模型和策略编码必须分开：

```text
场景
  -> Mid-360（激光雷达）真实扫描方向与顺序
  -> 原始点云
  -> 固定形状感知编码
  -> 演员策略
```

第一版采样依据官方 `mid360.csv（Mid-360 扫描模式文件）`：24,000 条采样、10 Hz（每秒 10 次）、
完整一帧 0.1 秒、水平 360 度、垂直约 -7.22 到 55.22 度。100 Hz 控制下每个控制周期发射约
2,400 条按 CSV（逗号分隔文件）顺序的射线，连续 10 个周期构成一帧扫描。

第一版编码采用 Gao-3200（高飞组 3200 维距离表示）：

- 多帧原始点云各自保存采样时间和无人机位姿。
- 策略读取时把历史点变换到当前机体系。
- 空间划分为 3,200 个方向区域，每区保留最近距离；远距离截断为固定最大距离。
- 小型 MLP（多层感知机）编码距离向量。

这一阶段先训练 Mid360-PPO（激光雷达近端策略优化）基线。演员输入是激光雷达特征、状态估计、
目标方向、上一动作和传感器年龄；不得直接读取障碍真值。

### 阶段 A2：D.VA（解耦视觉解析策略梯度）感知策略

D.VA（解耦视觉解析策略梯度）不是完整 APG（解析策略梯度）。它的演员将传感器观测作为常量，
保留“策略参数到动作到可微动力学到物理损失”的梯度，主动省略“状态到传感器观测到策略”的
梯度。因此传感器本身不需要可微。

```text
真实传感器观测切断梯度
  -> 演员动作
  -> Genesis（仿真器）可微动力学
  -> 连续安全与进度损失
  -> 演员参数

仿真完整状态和障碍真值
  -> 特权评论家
  -> 冻结目标评论家的终端成本梯度
```

演员使用部署可得观测；评论家可以使用无人机真值状态、障碍位置、障碍速度和目标信息。短窗口
必须有目标评论家终端价值，真实终止为零，时间截断继续自举。

### 阶段 A3：动态障碍时间信息

先增加简单历史距离，不在第一版同时增加点流网络。

- 第一条对照路线：把 36 个水平最近距离保存 36 帧，形成 36×36 距离时间图。
- 第二条对照路线：使用 Point to Motion（点到运动）表示。先构造 108×18 三维距离图，再最小池化为
  36×6，并增加水平和垂直点流，得到 3×36×6 输入。
- 动态障碍奖励和可微安全损失在训练时可使用附近障碍物的真值位置和速度，避免只依赖实际
  激光命中造成的随机奖励；这些真值不得输入演员。

### 阶段 A4：传感器真实性和部署差距

在策略已经能稳定避障后，再逐步加入：

- 每个射线的真实发射时间；
- 无人机和动态障碍在扫描期间的运动；
- 扫描运动畸变；
- 距离噪声、无效读数和丢失点；
- 状态估计误差和传感器外参误差。

此顺序避免在算法、感知编码和传感器真实性还未分别验证时同时引入多个变量。

## 算法边界

| 方法 | 当前用途 | 演员输入 | 评论家输入 | 是否要求传感器可微 |
| --- | --- | --- | --- | --- |
| APG（解析策略梯度） | 状态竞速与状态安全上界 | 完整可微状态 | 无 | 是，若输入包含传感器 |
| SHAC（短视域演员—评论家算法） | 状态竞速与状态安全 | 部署状态或状态任务输入 | 可使用特权状态 | 只对演员完整状态路径要求 |
| PPO（近端策略优化） | 所有阶段标准基线 | 与部署一致 | 可使用特权评论家输入 | 否 |
| D.VA（解耦视觉解析策略梯度） | Mid-360 感知动态避障 | 传感器特征和部署状态 | 仿真特权状态 | 否 |

“传感器不可微，所以不能训练感知策略”是错误表述。正确表述是：完整传感器 APG（解析策略梯度）
不能保留完整闭环观测梯度；D.VA（解耦视觉解析策略梯度）和 PPO（近端策略优化）仍可训练。

## 奖励、损失和指标的边界

所有任务都分为三层：

1. 共享事件和指标：穿门、错误方向、碰撞、任务完成、成功率、完成时间。
2. PPO（近端策略优化）奖励：允许使用穿门奖励、碰撞惩罚和完成奖励等离散事件。
3. 可微训练损失：必须使用连续物理量。竞速使用进度、加速度、加速度变化率、门向量场和门框安全；
   动态避障使用连续距离和相对接近速度。

动态避障的连续安全损失可以读取训练期障碍真值，但策略演员不能读取。这是训练期特权监督，
不是部署期依赖。

## 真实部署约束

- 竞速：门来自已知赛道地图和状态估计器；第一阶段不研究从传感器识别门。
- 动态避障：策略读取 Mid-360（激光雷达）和 LiDAR（激光雷达）加 IMU（惯性测量单元）状态估计，
  以及目标方向；不读取障碍真值。
- 所有部署策略继续使用 CTBR（总推力与机体角速度指令）接口。真实飞控、状态估计和安全保护层
  必须在真实机测试前单独验证。

## 后续讨论前必须冻结的问题

- Mid-360（激光雷达）安装外参、最大有效距离、历史帧数和控制频率如何与真实平台标定。
- 静态杂乱和动态障碍物的尺寸、密度、速度分布与真实任务边界。
- 目标方向任务的终点、超时和成功判定。
- D.VA（解耦视觉解析策略梯度）的评论家成本符号、网络结构和短窗口长度。
- 是否在动态避障完成后另建“感知竞速”研究；它不属于当前状态竞速路线的自动下一步。
- 真实机安全保护、状态估计质量门槛和仿真到真实随机化范围。

这些问题在进入感知动态避障时再通过 `grill-with-docs（带文档的追问）`、`to-spec（转规格）`
和 `to-tickets（拆工单）` 冻结。当前不得为它们创建实施工单。
