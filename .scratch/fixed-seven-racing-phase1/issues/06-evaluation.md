# 06 — 三算法统一评价与真实碰撞验证

**What to build（实施目标）：** 三种算法读取同一份 100 组固定初始状态，并在打开真实门框接触的同一环境中评价。解析碰撞或真实碰撞任一触发都计为失败。

**Blocked by（前置工单）：** 03 — 固定七门 PPO（近端策略优化）完整基线；04 — 完整 APG（解析策略梯度）固定七门训练；05 — 正确 SHAC（短视域演员—评论家算法）固定七门训练。

**Status（状态）：** ready-for-agent（可交给智能体）

- [x] 固定评价初始状态可保存、加载并验证校验值。
- [x] 评价记录完整七门成功、解析碰撞、真实碰撞、完成时间、逐门时间、平均速度和路径效率。
- [x] 三种算法的赛道、初始分布、动作、观测、控制频率、控制器和时间限制自动比较一致。
- [x] 同一策略在软碰撞训练模式和真实碰撞评价模式中可以加载运行。
